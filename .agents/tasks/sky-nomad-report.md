## 如何运行

- 构建：没有构建步骤，也不需要安装依赖。只需要 Node（本次验证用的是 v24.18.1）。
- 启动：`node tools/serve.mjs`（或 `npm run serve`），然后打开 http://localhost:5173/ 。ES modules 不能通过 `file://` 加载，所以需要这个本地服务器。
- 手机访问：PowerShell 里执行 `$env:HOST='0.0.0.0'; node tools/serve.mjs`，在同一 Wi-Fi 下访问 `http://<电脑IP>:5173/`。这个服务器没有鉴权，只适合在可信网络里用。
- 测试：`node --test`（或 `npm test`）。

## 本次验证内容

1. 准备：工作区是干净的提交 `869fb43`，没有依赖需要安装。
2. `node --test`：52 个测试，52 个通过，0 个失败（约 1.1 秒）。
3. 浏览器验证：在后台启动 `node tools/serve.mjs`，运行 `node .agents/tasks/browser-check.mjs`，结果 42/42 通过，检查结束后服务器已停止。脚本用 headless Chrome 和 CDP 模拟 iPhone 390×844 @3x 的触摸操作，覆盖了下面这些内容：
   - 缩放：画布内部尺寸 180×320，CSS 尺寸 360×640，居中显示，周围填 `rgb(27,42,92)`，`image-rendering: pixelated`。另外检查了桌面 1280×720 和 1080×1920 两种尺寸。
   - 标题 → 选关，未解锁的关卡点不进去；拖动按相对位移移动并被限制在屏幕内；第 1 关只出现陨石。

   - 第 2 关流星出现预警；失败后"再来一次"和"选关"都正常；刷新页面后解锁进度还在。
   - 静音按钮能切换并持久化，点击不会传给场景。
   - 第 5 关最后 10 秒才出现大飞船；3 星过关 → 通关画面 → 回到标题。
   - 页面切到后台时暂停并挂起音频，回来后点击继续。
   - 全程没有控制台错误。
4. 人工看了截图（`.agents/tasks/screens/`，未提交到 git）：第 5 关画面里大飞船、彗星彩虹尾、飞碟、护盾光环、HUD 都显示正常；过关画面的星级、纸屑和按钮也正常，像素边缘锐利。

## 推迟 / 未解决事项（均不阻断）

- 没有验证真实声音的听感，也没有在真机（iOS Safari / Android Chrome）上测试触摸和音频解锁。目前只在 Chrome 设备模拟里确认了 AudioContext 的创建、挂起和恢复。
- 整数倍缩放按 CSS 像素计算，没有考虑 devicePixelRatio。在 DPR 为 2.625 这类非整数的安卓机上，像素块宽度可能不均匀。
- 静音按钮的命中区（右上角 18×18 逻辑像素）在游戏中会吞掉从这块区域开始的拖动。
- 第 3、4 关没有生成器的全程模拟测试，只测了关卡配置。
- 大飞船按"半宽 70%"算碰撞圆，两翼约 5px 没有碰撞体积。这是设计文档本身的规则，如果试玩觉得手感不对，应该修改设计。
- 画面上的中文文字是在 180×320 画布上绘制再放大的，边缘有轻微的抗锯齿灰边，能看清。
- 浏览器检查为了缩短时间，用脚本直接推进关卡时间；整关实时跑完的情况由 node 测试的全程模拟覆盖。
