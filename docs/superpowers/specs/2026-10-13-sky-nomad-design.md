# Sky Nomad 设计文档

手机浏览器竖版像素风躲避游戏。Q 版、明亮、不恐怖。

## 技术
- 原生 HTML5 Canvas + ES modules，无依赖、无构建。
- 像素画用字符矩阵定义，启动时渲染到离屏 canvas 缓存。
- 音乐/音效用 Web Audio 实时合成 8-bit。首次点击时初始化 AudioContext。
- 逻辑分辨率 180×320，整数倍缩放（不足整数倍时取最大整数倍，余下区域填背景色），`image-rendering: pixelated`。

## 操作
- 触摸/鼠标在任意位置按下拖动，飞机按相对位移移动，限制在屏幕内。

## 规则
- 5 滴血，碰撞扣 1，之后 1.5 秒无敌闪烁。
- 道具：星星（+10 分）、爱心（+1 血，上限 5）、护盾（5 秒无敌）。
- 每关坚持指定时长即过关；顶部进度条。
- 血量为 0：失败，可重玩本关。已解锁关卡存 localStorage（key `skyNomad.unlocked`）。
- 过关评星：剩余血量 5 → 3 星，3~4 → 2 星，1~2 → 1 星。

## 障碍物
| 类型 | 行为 |
|---|---|
| meteor 陨石 | 直线下落、旋转，大/小 |
| shooting 流星 | 快速斜向，出现前 0.6 秒边缘预警 |
| comet 彗星 | 正弦弧线下落，彩虹尾巴 |
| alien 小飞碟外星人 | 左右摇摆下降 |
| ship 大飞船 | 慢速下降+横移，体积大 |

碰撞判定：圆形，半径为图像半宽的 ~70%。

## 关卡
| 关 | 名称 | 时长 | 障碍 |
|---|---|---|---|
| 1 | 陨石带 | 45s | meteor |
| 2 | 流星雨 | 50s | meteor, shooting |
| 3 | 外星人来访 | 55s | alien, meteor |
| 4 | 彗星之路 | 60s | comet, shooting, alien |
| 5 | 银河大冒险 | 70s | 全部，最后 10s 加 ship |

生成间隔随关卡内进度从 `spawnStart` 线性降到 `spawnEnd`。

## 场景
标题 → 选关 → 游戏 → 过关庆祝（烟花纸屑、飞机转圈、胜利音效、星级）/ 失败（再来一次 / 选关）→ 第 5 关后通关画面。右上角静音按钮。

## 测试
Node 内置 `node --test` 测试纯逻辑：碰撞、关卡生成配置、评星、存档。浏览器手动验证。
